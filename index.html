Poker Executives Setup

Manager Start Here
Set up the event in four simple steps. PokerEx will use the Start-time / prior-hours EO rule automatically: earlier scheduled start time first, then the dealer with the most hours worked before today.
1Create the event
Name the event and enter its dates.
2Upload roster + schedule
One CSV can add dealers, PINs, and every scheduled shift. Required dealer column: Dealer. Recommended columns: Dealer Number, PIN, Date, Start, End, Shift.
If PIN is blank and a 3-digit Dealer Number is present, PokerEx creates the temporary PIN by adding a leading zero (123 → 0123) and requires a new PIN at first login. Rows with no Date/Start add the dealer only.

  


  

    3EO priority
    
Scheduled Start + Prior Hours
Earlier scheduled start times are ranked first. Dealers with the same start time are ranked by total completed hours from previous days. Current-day hours do not count. If still tied, EO signup time breaks the tie.
